# Gold Miner — 금거래소 매입·매도 타이밍 인텔리전스

금 가격 측정과 과거 데이터 기반 미래 분석으로 금거래소의 매입·매도 판단을 돕는 대시보드입니다.

## 바로 보기
- `site/dist/index.html` — **메인 보드** (비전문가용: 싼가/비싼가, 과거 비슷한 때, 매수 계획, 매도 신호)
- `site/dist/analysis.html` — **상세 분석** (가격·거시 분석, 시그널, 예측, 백테스트 랩, 거래 데스크, 데이터 품질)
- 두 파일은 데이터가 내장된 단일 파일이며 같은 폴더에 두면 서로 링크됩니다.
- 개발용 원본: `site/index.html`, `site/analysis.html` (`site/data/gm_data.js`, `site/js/engine.js`를 읽음)

## 데이터 갱신 (Phase 1 ETL)
```bash
python etl/gold_miner_etl.py        # 수집 → 품질 검사 → data/clean, site/data/gm_data.js 생성
node etl/build_models.js            # Phase 4 모델(시그널 검증·가격 범위·국면) 사전 계산 → site/data/gm_models.js
python etl/build_standalone.py      # site/dist/index.html, analysis.html 재생성
python -m unittest discover etl     # ETL 테스트
node --test site/js/engine.test.js  # 백테스트 엔진 테스트 (미래 데이터 참조 방지 포함)
```
표준 라이브러리만 사용합니다(Python 3.9+). 네트워크 허용 필요 호스트: `fred.stlouisfed.org`, `query1.finance.yahoo.com` (`stooq.com`은 예비).

| 데이터 | 소스 | 시리즈 |
|---|---|---|
| 금 가격 (일별) | Yahoo Finance | COMEX 금 선물 GC=F (2000-08~) |
| 실질금리 | FRED | DFII10 |
| 달러 인덱스 | FRED | DTWEXBGS |
| 기대인플레이션 | FRED | T10YIE |
| 10Y 국채 | FRED | DGS10 |
| USD/KRW | FRED | DEXKOUS |

미연결(수동 입력): KRX 금 시세, WGC 중앙은행 수요, CFTC 포지션 → 이후 Phase에서 연결.

### 백테스트 규칙 (`site/js/engine.js`)
- 목표 비중은 그날 종가까지의 정보로만 계산하고, 체결은 다음 날 종가(기본) 또는 당일 종가에 합니다.
- 거시 지표는 관측일 다음 날부터만 사용합니다(발표 지연 반영).
- 거래비용은 매매한 비중에 편도 비율로 차감하고, 금을 보유하지 않은 비중은 현금 금리를 받습니다.
- 워크포워드: 매년 직전 5년 데이터로 이동평균 조합(빠른 10~100일 × 느린 100~250일) 중 샤프 최고를 고르고, 다음 1년은 처음 보는 데이터로 운용합니다.

### 메인 보드 판단 규칙
- **가격 온도**: 오늘 가격이 200일(1년 흐름)·1,000일(4년 흐름) 평균선에서 떨어진 정도를, 그날 이전의 과거 값들과 비교한 백분위(0~100). 매우 저렴 <20 ≤ 저렴 <40 ≤ 보통 <60 ≤ 비쌈 <80 ≤ 매우 비쌈.
- **과거 비슷한 때**: 두 온도의 구간이 지금과 같았던 모든 날의 1년 뒤 수익률 분포.
- **매수 계획**: 공격형(오늘 60%·3회), 균형형(30%·6회), 안정형(15%·12회), 회차 간격 1개월. 각 방식의 과거 평균 매입 단가를 일시 매수와 비교해 표시.
- **매도 신호**: 4년 평균선 이탈, 50/200일선 하락 교차, 과열(1년 온도 90↑ & 4년 온도 85↑).
- 데이터상 금은 "싸 보일 때"보다 "추세가 살아 있을 때"의 성과가 좋았고, 분할 매수는 평균 단가를 낮추지 못했습니다(보험 성격). 화면에도 그대로 표시합니다.

### Phase 4 검증 결과 (2026-11-27 데이터)
| 모델 | 결과 | 채택 |
|---|---|---|
| 매입·매도 시그널 | 이후 1·3·6개월 수익률과 순위 상관(IC) 0.009 / −0.025 / 0.006 → **예측력 없음** | 설명 지표로만 사용 |
| 유사 국면(최근접 이웃) 예측 | 단순 기준선보다 분위수 오차 3~20% 큼 | 미채택 |
| 보정 혼합 범위 모델 | 정확도는 기준선과 비슷(−1.3~+0.9%), **80% 범위 적중 78~82%** (기준선 65~79%) | 채택 (메인 "앞으로 1년" · 상세 "12개월 범위") |
| 3상태 HMM 국면 | 급락(연 −37%, 변동성 46%) · 안정(+9%, 14%) · 고변동(+23%, 19%) | 국면 설명용 |

- 보정 혼합 모델 = (과거 수익률 분포 + 현재 변동성으로 크기를 조정한 분포)의 평균, 그 뒤 과거 예측 오차로 범위를 넓힘. 넓히는 비율은 매 시점 그 이전에 결과가 확인된 예측만으로 정합니다.
- 결론: 금 가격의 **방향**은 어떤 모델로도 기준선보다 잘 맞히지 못했습니다. 사이트는 방향 대신 "움직일 수 있는 범위"를 보여줍니다.
