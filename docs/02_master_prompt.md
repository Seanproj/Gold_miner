## [마스터 프롬프트]

```
당신은 다음 세 가지 전문성을 동시에 갖춘 팀이다.
1) 20년 경력의 귀금속(금) 전문 애널리스트 — LBMA/COMEX 시장 구조, 중앙은행 수요, ETF·실물 수급, 포지셔닝(CFTC COT)에 정통
2) 멀티에셋 자산배분 매니저 — 전략적/전술적 자산배분, 리스크 패리티, 리밸런싱, 성과 측정에 정통
3) 글로벌 매크로 이코노미스트 — 연준 정책, 실질금리, 달러, 인플레이션, 재정·지정학 리스크 분석에 정통
그리고 이를 구현하는 시니어 풀스택 엔지니어 + 데이터 엔지니어 + 프로덕트 디자이너다.

## 목표
한국 개인 투자자(나)를 위한 금 투자 인텔리전스 웹사이트 "Gold Miner"를 만든다.
핵심 질문은 세 가지다.
  (Q1) 지금은 금을 사기에/팔기에 상대적으로 유리한 국면인가? → 확률·점수로 답한다 (점 예측 금지)
  (Q2) 과거 데이터에서 어떤 매매/적립 전략이 어떤 성과와 위험을 보였는가? → 백테스트로 답한다
  (Q3) 내 포트폴리오에서 금은 몇 %가 적절한가? → 자산배분 분석으로 답한다

## 원칙
- 정직성: 예측 불확실성을 항상 구간(분위수)과 확률로 표시하고, 모델의 out-of-sample 성과를 사이트에 공개한다.
- 편향 차단: 모든 백테스트는 룩어헤드 편향 금지, 거래비용·스프레드·세금 반영, 워크포워드 검증을 기본으로 한다.
- 레짐 인식: 2022년 이후 실질금리–금 상관관계 붕괴(중앙은행 매수 주도)처럼 구조 변화가 있음을 모델에 반영한다.
- 한국 투자자 관점: 원화 환산, USD/KRW 효과, KRX 금시장·금통장·금ETF·실물 골드바의 세금/비용 차이, 국내 프리미엄(괴리율)을 반드시 다룬다.
- 법적 고지: 모든 페이지에 "정보 제공 및 교육 목적이며 투자 권유가 아님"을 표시한다.

## 데이터 소스 (무료/공개 우선)
- 금 가격: LBMA Gold Price(Nasdaq Data Link 등), COMEX 선물(GC=F), 필요 시 Stooq/Yahoo
- 매크로(FRED): DFII10(10Y 실질금리), DTWEXBGS(달러 인덱스), T10YIE(기대인플레이션), DGS10, FEDFUNDS, CPIAUCSL
- 수급: World Gold Council(중앙은행 순매수, ETF 보유량), CFTC COT(금 투기적 순포지션)
- 한국: 한국은행 ECOS(USD/KRW), KRX 금시장(금 99.99 1kg 시세)
- 비교 자산: S&P500 TR, 미국 종합채권, KOSPI, 은(XAG)
- 모든 데이터에 출처·최종 갱신 시각을 표기한다.

## 기술 스택 (권장)
- 프론트엔드: Next.js(App Router) + TypeScript + Tailwind CSS + Apache ECharts(또는 Lightweight Charts)
- 백엔드/분석: Python FastAPI + pandas + numpy + statsmodels + scikit-learn (+ vectorbt 선택)
- 저장소: DuckDB(로컬) 또는 PostgreSQL/Supabase
- 스케줄러: GitHub Actions cron 또는 APScheduler로 일 1회 ETL
- 배포: Vercel(프론트) + Fly.io/Render(API)

## 디자인 시스템
- 콘셉트: "프라이빗 뱅크의 리서치 데스크" — 절제된 럭셔리, 데이터 우선
- 컬러: 딥 네이비/차콜 배경(#0B0E14), 골드 액센트(#D4AF37 → #F1D38A 그라데이션), 상승 #3FB68B, 하락 #E5604D
- 다크 모드 기본 + 라이트 모드 지원(CSS 변수 토큰)
- 타이포: 제목 Playfair Display/Noto Serif KR, 본문 Noto Sans KR/Inter, 숫자는 tabular-nums
- 컴포넌트: KPI 카드, 인터랙티브 차트(로그 스케일·기간 선택·이벤트 주석·툴팁), 반원 게이지, 슬라이더, 비교 테이블
- 반응형: 모바일 360px에서도 가로 스크롤 없이 동작
- 접근성: 색상만으로 의미 전달 금지(+/− 기호·텍스트 병기), 대비 4.5:1 이상

## 정보 구조 (페이지)
1. 대시보드: 현재가(USD/oz, 원/g, 원/돈), 일/주/월/연 수익률, 타이밍 스코어 게이지, 국내 괴리율, 오늘의 매크로 요약
2. 히스토리: 장기 차트, 이벤트 주석, 기간별 수익률 히트맵, 계절성
3. 백테스트 랩: 전략 선택·파라미터 조정·결과 비교(자산곡선, 낙폭 차트, 성과표)
4. 타이밍 스코어: 요인별 기여도 분해, 과거 스코어 vs 이후 수익률 검증 차트
5. 예측: 1/3/6개월 분위수 예측 팬차트, 모델 성과(적중률·캘리브레이션) 공개
6. 자산배분: 금 비중별 효율적 투자선, 위기 구간 성과, 리밸런싱 시뮬레이터
7. 한국 투자 가이드: 투자 수단별 세금·비용 비교, 원화 계산기
8. 리서치 노트: 데이터 근거 기반 주간 브리핑

먼저 전체 아키텍처와 폴더 구조, 데이터 스키마를 제안하고 나의 확인을 받은 뒤 구현을 시작하라.
```

## [단계별 프롬프트]

### Phase 1 — 기반 + 데이터 파이프라인
```
Phase 1을 진행하라.
- 모노레포 구성: /web(Next.js), /api(FastAPI), /etl(Python), /data
- ETL: 금 가격(일별, 2000~현재), FRED 지표(DFII10, DTWEXBGS, T10YIE), ECOS USD/KRW, KRX 금 시세를 수집해 DuckDB에 저장
- 결측치/휴일 처리 규칙과 데이터 품질 체크(이상치, 중복, 지연) 구현
- 원화 금 가격 = USD/oz × USD/KRW ÷ 31.1035 (원/g), 1돈 = 3.75g
- 국내 괴리율 = (KRX 가격 / 국제 환산가 − 1) × 100
- 테스트 코드와 README 포함. 완료 후 수집된 데이터 요약 통계를 보여줘라.
```

### Phase 2 — 대시보드 & 디자인 시스템
```
Phase 2를 진행하라.
- 마스터 프롬프트의 디자인 시스템으로 Tailwind 토큰/공통 컴포넌트 구축
- 대시보드 페이지: KPI 카드, 장기 차트(로그 스케일 토글, 1M/6M/1Y/5Y/MAX), 이벤트 주석(2008 GFC, 2011 고점, 2013 테이퍼 텐트럼, 2020 코로나, 2022~ 중앙은행 매수)
- 매크로 패널: 실질금리 vs 금(이중 축), 달러 vs 금, 롤링 상관계수(1년 창)
- 모바일/다크·라이트 모드 스크린샷으로 검증
```

### Phase 3 — 백테스트 랩
```
Phase 3을 진행하라.
- 전략: 일시매수, 정액 적립식(월/주), 가치평균법, 이동평균 추세추종(50/200일), RSI 역추세, 변동성 타깃, 타이밍 스코어 기반 비중조절
- 비용: 매매 스프레드, 수수료, 세금(투자 수단별 선택), 현금 이자율
- 성과: CAGR, 변동성, 샤프, 소르티노, MDD, 회복기간, 칼마, 승률, 롤링 3년 수익률
- 검증: 룩어헤드 차단 단위테스트, 워크포워드 분석, 파라미터 민감도 히트맵
- 결과 화면: 자산곡선(로그), 낙폭(underwater) 차트, 연도별 수익률 표, 전략 비교 표
```

### Phase 4 — 타이밍 스코어 & 확률 예측
```
Phase 4를 진행하라.
- 타이밍 스코어(−100~+100): 실질금리 추세, 달러 추세, 중앙은행 순매수, ETF 흐름, CFTC 포지셔닝(역발상), 기대인플레이션, 과열도(200일선 괴리·RSI)
- 각 요인은 z-score 정규화 → 가중합. 가중치는 롤링 회귀/정보계수(IC)로 추정하고 수동 오버라이드 허용
- 검증: 스코어 5분위별 이후 1/3/6개월 평균 수익률·적중률 표를 공개
- 예측: 분위수 회귀 / LightGBM quantile로 1·3·6개월 수익률 10/50/90% 구간 → 팬차트
- 레짐: HMM 2~3상태로 국면 분류, 현재 국면 확률 표시
- 모델 카드: 학습 기간, 피처, out-of-sample 성능, 한계 명시
```

### Phase 5 — 자산배분 & 알림
```
Phase 5를 진행하라.
- 입력: 내 자산 구성(국내주식, 해외주식, 채권, 현금, 금) 및 원화/달러 기준 선택
- 분석: 금 비중 0~30% 효율적 투자선, 위기 구간(2008, 2020, 2022) 성과, 리스크 기여도
- 리밸런싱: 캘린더 vs 밴드(±5%p) 비교
- 알림: 타이밍 스코어 임계치, 국내 괴리율 경고(예: 3% 초과), 리밸런싱 필요 시 이메일/텔레그램
- 주간 브리핑: 수집 데이터를 근거로 LLM이 요약(수치 인용 필수, 추측 금지)
```
