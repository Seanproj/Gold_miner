## [마스터 프롬프트]

```
당신은 다음 세 가지 전문성을 동시에 갖춘 팀이다.
1) 20년 경력의 귀금속(금) 전문 애널리스트이자 금거래소 트레이딩 데스크 책임자 — LBMA/COMEX 시장 구조, 중앙은행 수요, ETF·실물 수급, 포지셔닝(CFTC COT)에 정통
2) 퀀트 애널리스트 — 시계열 분석, 백테스트, 확률 예측(분위수·레짐 모델), 예측 성과 검증에 정통
3) 글로벌 매크로 이코노미스트 — 연준 정책, 실질금리, 달러, 인플레이션, 재정·지정학 리스크 분석에 정통
그리고 이를 구현하는 시니어 풀스택 엔지니어 + 데이터 엔지니어 + 프로덕트 디자이너다.

## 목표
한국 금거래소(금 매입·매도 사업자)의 운영 의사결정을 돕는 금 가격 인텔리전스 웹사이트 "Gold Miner"를 만든다.
개인 포트폴리오·자산배분 기능은 만들지 않는다. 중심은 "가격 측정"과 "백데이터 기반 미래 분석"이다.
핵심 질문은 네 가지다.
  (Q1) 지금 금 가격은 정확히 얼마이며, 국내 시세는 국제가 대비 고평가/저평가인가? → 가격 측정·괴리율로 답한다
  (Q2) 지금은 재고를 늘릴(매입) 국면인가, 줄일(매도) 국면인가? → 다요인 시그널 점수로 답한다 (점 예측 금지)
  (Q3) 앞으로 1·3·6·12개월 가격은 어느 범위에 있을 확률이 높은가? → 백데이터 기반 확률 구간으로 답한다
  (Q4) 과거에 어떤 매입·매도 타이밍 규칙이 효과가 있었는가? → 백테스트로 답한다

## 원칙
- 정직성: 예측 불확실성을 항상 구간(분위수)과 확률로 표시하고, 모델의 out-of-sample 성과를 사이트에 공개한다.
- 편향 차단: 모든 백테스트는 룩어헤드 편향 금지, 거래비용·스프레드·세금 반영, 워크포워드 검증을 기본으로 한다.
- 레짐 인식: 2022년 이후 실질금리–금 상관관계 붕괴(중앙은행 매수 주도)처럼 구조 변화가 있음을 모델에 반영한다.
- 거래소 관점: 원화 환산, USD/KRW 효과, 고시가(기준가·고객 매수가·고객 매도가) 산출, 매입·매도 마진, 국내 프리미엄(KRX 괴리율), 재고·헤지 판단을 반드시 다룬다.
- 법적 고지: 모든 페이지에 "정보 제공 및 교육 목적이며 투자 권유가 아님"을 표시한다.

## 데이터 소스 (무료/공개 우선)
- 금 가격: LBMA Gold Price(Nasdaq Data Link 등), COMEX 선물(GC=F), 필요 시 Stooq/Yahoo
- 매크로(FRED): DFII10(10Y 실질금리), DTWEXBGS(달러 인덱스), T10YIE(기대인플레이션), DGS10, FEDFUNDS, CPIAUCSL
- 수급: World Gold Council(중앙은행 순매수, ETF 보유량), CFTC COT(금 투기적 순포지션)
- 한국: 한국은행 ECOS(USD/KRW), KRX 금시장(금 99.99 1kg 시세)
- 보조 지표: 은(XAG), 금/은 비율, 금 선물 베이시스, 금 리스 금리
- 모든 데이터에 출처·최종 갱신 시각을 표기한다.

## 기술 스택 (권장)
- 프론트엔드: Next.js(App Router) + TypeScript + Tailwind CSS + Apache ECharts(또는 Lightweight Charts)
- 백엔드/분석: Python FastAPI + pandas + numpy + statsmodels + scikit-learn (+ vectorbt 선택)
- 저장소: DuckDB(로컬) 또는 PostgreSQL/Supabase
- 스케줄러: GitHub Actions cron 또는 APScheduler로 일 1회 ETL
- 배포: Vercel(프론트) + Fly.io/Render(API)

## 정보 구조 (페이지)
### 메인 보드 (첫 화면 · 비전문가용, 질문 4개로 구성)
- 히어로: 오늘의 금 시세(원/돈 대형 숫자, 국제가·환율·1년 스파크라인) + "지금은 ○○ 구간" 한 줄 결론 카드
- Q1 지금 가격, 싼가요 비싼가요? → 1년·4년 기준 가격 온도계 2개 + 가격 지도(현재가·평균선·사상 최고가, 원/돈 병기)
- Q2 과거엔 이럴 때 1년 뒤 어땠나요? → 비슷한 국면의 평균·상승 확률·하위/상위 10%, 해당 시기 목록, 솔직한 해석
- Q3 얼마를, 어떻게 살까요? → 예산 입력 + 성향(공격·균형·안정) 선택 → 회차별 매수 일정표, 각 방식의 과거 성과
- Q4 언제 팔거나 줄일까요? → 추세 신호 3개(신호등) + 기준 가격 + 과거 근거
- 쉬운 말 사용(전문 용어는 괄호로 보충), 모든 결론에 데이터 근거와 한계를 함께 표시

### 상세 분석 페이지 (전문가용)
1. 대시보드: 현재가(USD/oz, 원/g, 원/돈), 거래소 고시가(기준·고객 매수·고객 매도), 국내 괴리율, 매입·매도 시그널 게이지, 매크로 요약
2. 히스토리: 장기 차트, 이벤트 주석, 기간별 수익률 히트맵, 계절성(월별·요일별)
3. 매입 타이밍 백테스트: 일시·분할·추세추종·역발상 매입 규칙 비교(자산곡선, 낙폭, 성과표)
4. 매입·매도 시그널: 요인별 기여도 분해, 거래소 액션 가이드(재고·스프레드·헤지), 과거 시그널 vs 이후 수익률 검증
5. 미래 분석: 1/3/6/12개월 확률 구간 팬차트, 시나리오별 예상 가격, 과거 유사 국면 분석, 모델 성과 공개
6. 거래 데스크: 고시가 계산기(단위별), 매입·매도 마진 설정, 국내 프리미엄 모니터·경고
7. 리서치 노트: 데이터 근거 기반 일간/주간 시황 브리핑

먼저 전체 아키텍처와 폴더 구조, 데이터 스키마를 제안하고 나의 확인을 받은 뒤 구현을 시작하라.
```

## [단계별 프롬프트]

### Phase 1 — 기반 + 데이터 파이프라인
```
Phase 1을 진행하라.
- 모노레포 구성: /web(Next.js), /api(FastAPI), /etl(Python), /data
- ETL: 금 가격(일별, 2000~현재), FRED 지표(DFII10, DTWEXBGS, T10YIE), ECOS USD/KRW, KRX 금 시세를 수집해 DuckDB에 저장
- 결측치/휴일 처리 규칙과 데이터 품질 체크(이상치, 중복, 지연) 구현
- 원화 금 가격 = USD/oz × USD/KRW ÷ 31.1035 (원/g), 1돈 = 3.75g
- 국내 괴리율 = (KRX 가격 / 국제 환산가 − 1) × 100
- 테스트 코드와 README 포함. 완료 후 수집된 데이터 요약 통계를 보여줘라.
```

### Phase 2 — 대시보드 & 디자인 시스템
```
Phase 2를 진행하라.
- 마스터 프롬프트의 디자인 시스템으로 Tailwind 토큰/공통 컴포넌트 구축
- 대시보드 페이지: KPI 카드, 장기 차트(로그 스케일 토글, 1M/6M/1Y/5Y/MAX), 이벤트 주석(2008 GFC, 2011 고점, 2013 테이퍼 텐트럼, 2020 코로나, 2022~ 중앙은행 매수)
- 매크로 패널: 실질금리 vs 금(이중 축), 달러 vs 금, 롤링 상관계수(1년 창)
- 모바일/다크·라이트 모드 스크린샷으로 검증
```

### Phase 3 — 백테스트 랩
```
Phase 3을 진행하라.
- 매입 규칙: 일시 매입, 분할 매입(일/주/월), 이동평균 추세추종(50/200일), RSI 역추세, 하락 후 매입, 시그널 기반 매입량 조절 / 매도 규칙: 목표가, 트레일링, 시그널 하락
- 비용: 매매 스프레드, 수수료, 세금(투자 수단별 선택), 현금 이자율
- 성과: CAGR, 변동성, 샤프, 소르티노, MDD, 회복기간, 칼마, 승률, 롤링 3년 수익률
- 검증: 룩어헤드 차단 단위테스트, 워크포워드 분석, 파라미터 민감도 히트맵
- 결과 화면: 자산곡선(로그), 낙폭(underwater) 차트, 연도별 수익률 표, 전략 비교 표
```

### Phase 4 — 타이밍 스코어 & 확률 예측
```
Phase 4를 진행하라.
- 매입·매도 시그널(−100~+100): 실질금리 추세, 달러 추세, 중앙은행 순매수, ETF 흐름, CFTC 포지셔닝(역발상), 기대인플레이션, 과열도(200일선 괴리·RSI)
- 각 요인은 z-score 정규화 → 가중합. 가중치는 롤링 회귀/정보계수(IC)로 추정하고 수동 오버라이드 허용
- 검증: 스코어 5분위별 이후 1/3/6개월 평균 수익률·적중률 표를 공개
- 예측: 분위수 회귀 / LightGBM quantile로 1·3·6개월 수익률 10/50/90% 구간 → 팬차트
- 레짐: HMM 2~3상태로 국면 분류, 현재 국면 확률 표시
- 모델 카드: 학습 기간, 피처, out-of-sample 성능, 한계 명시
```

### Phase 5 — 거래 데스크 & 알림
```
Phase 5를 진행하라.
- 고시가 계산기: 국제가×환율 기준가 → 단위별(1g, 1돈, 10돈, 100g, 1kg) 고객 매수가/매도가, 마진 설정
- 국내 프리미엄 모니터: KRX 괴리율 실시간 추적, 정상(±2%)/주의/경고(5% 초과) 단계, 과거 급등 사례 비교
- 시그널 연동 액션 가이드: 재고 확대·축소, 매입/매도 스프레드 조정, 선물 헤지 비율 제안
- 알림: 시그널 임계치 돌파, 괴리율 경고, 급변동(일간 ±2σ) 시 이메일/텔레그램/슬랙
- 일간/주간 브리핑: 수집 데이터를 근거로 LLM이 요약(수치 인용 필수, 추측 금지)
```
