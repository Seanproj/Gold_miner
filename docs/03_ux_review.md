# Gold Miner — UX/UI 리뷰 & 개선 내역

> 관점: 그래픽·UX/UI 디자인 30년 차 디렉터
> 대상: `site/index.html`(메인 보드), `site/analysis.html`(상세 분석) — 2026-11-27 버전
> 기준: 2025–26 대시보드·핀테크 트렌드(벤토 그리드, 한눈에 보는 요약, 의미 기반 색, 절제된 모션, 국내 금융 앱 관례)

## 총평
데이터의 정직성과 질문형 구조(Q1~Q4)는 이 서비스의 가장 큰 강점이다. 일반 금융 사이트에서 보기 힘든 "솔직한 해석"은 신뢰를 만든다.
반면 **첫 화면에서 답을 다 보여주지 못하고**, **색의 의미가 한국 사용자 관례와 어긋나며**, **두 페이지의 내비게이션이 서로 달라** "잘 만든 제품"이라는 인상을 깎는다. 시각적 완성도는 80점, 사용성은 70점 수준이다.

| 영역 | 점수 (개선 전) | 핵심 문제 |
|---|---|---|
| 정보 구조 | 7/10 | 핵심 결론 4개가 스크롤 아래에 흩어짐 |
| 색 체계 | 6/10 | 상승=초록·하락=빨강(해외식), 가격 온도에 좋음/나쁨 색 사용 |
| 일관성 | 6/10 | 메인은 상단 탭, 상세는 사이드바 — 서로 다른 앱처럼 보임 |
| 타이포 | 7/10 | 한글 본문 서체가 Inter 대체 글꼴에 의존, 11px 보조 텍스트 |
| 가독성·접근성 | 6/10 | 보조 텍스트 대비 3.4:1(기준 4.5:1 미달), 긴 문단 |
| 시각 완성도 | 8/10 | 다크 톤·카드·그라데이션은 좋음, 이모지 아이콘이 고급감을 깎음 |
| 모션·피드백 | 5/10 | 로딩·전환 모션 없음 |

## 발견 사항 & 처방

### P0 — 바로 고쳐야 할 것
1. **상승·하락 색이 국내 관례와 반대.** 국내 증권·금 시세 앱은 상승=빨강▲, 하락=파랑▼이다. 초록=상승은 해외 사용자에게만 자연스럽다.
   → 기본값을 **한국식(빨강▲/파랑▼)**으로 하고, 헤더에서 **글로벌식(초록/빨강)** 전환을 제공한다. 색 외에 ▲▼ 기호를 항상 함께 쓴다.
2. **가격 온도에 "좋음/나쁨" 색(초록→빨강)을 사용.** 데이터상 "싸다 = 좋다"가 아닌데 초록이 그렇게 읽힌다.
   → **온도 은유**로 바꾼다: 차가움(파랑, 저렴) → 중립(회색) → 뜨거움(주황·빨강, 비쌈). 가치 판단 없이 위치만 전달한다.
3. **첫 화면에 결론이 다 안 보임.** 사용자는 첫 화면에서 "싼가? 과거엔? 추세는?"을 모두 원한다.
   → 히어로를 **벤토 그리드**로 바꾼다: [오늘 시세] + [한 줄 결론] + 한눈에 보는 타일 4개(1년 온도·4년 온도·과거 비슷한 때·추세 신호). 각 타일을 누르면 해당 Q 섹션으로 이동한다.
4. **페이지마다 다른 내비게이션.** 
   → 두 페이지에 **같은 글로벌 헤더**(로고·탭·데이터 기준일·설정)를 둔다. 상세 페이지의 사이드바는 "이 페이지 안의 목차" 역할로만 쓴다.
5. **대비 부족.** 보조 텍스트(#68748C on #111A2B)는 3.4:1이다.
   → 보조 텍스트 색을 대비 4.5:1 이상으로 올리고, 최소 글자 크기를 12px로 맞춘다.

### P1 — 완성도를 끌어올릴 것
6. **이모지 아이콘(📉🕰️🧭📈🧪🏦)** → 같은 선 굵기의 SVG 아이콘 세트로 통일한다.
7. **긴 설명 문단** → 핵심 수치는 한 줄로 보여주고, 근거는 "왜 그런가요?" 펼치기(`details`)로 숨긴다. 필요한 사람만 깊이 읽게 한다.
8. **섹션 이동이 어려움** → 메인 헤더 아래에 고정 섹션 칩(한눈에·Q1~Q4)을 두고, 스크롤 위치에 맞춰 강조한다.
9. **정적인 첫인상** → 큰 숫자 카운트업, 히어로 카드가 차례로 나타나는 모션을 넣는다(`prefers-reduced-motion`이면 끔).
10. **데이터 신뢰 표시가 약함** → 헤더에 "실데이터 · 2026-11-27 기준" 표시를 상시 노출한다.

### P2 — 다듬기
11. **한글 서체** → 국내 서비스 표준이 된 **Pretendard**(가변 서체)를 우선 쓰고, 불러오지 못하면 Noto Sans KR로 대체한다. 숫자는 tabular-nums.
12. **공통 스타일 중복** → 색 토큰·헤더·설정은 `site/css/theme.css`, 테마·색 관례 전환은 `site/js/ui.js`로 분리해 두 페이지가 같은 디자인 시스템을 쓰게 한다.
13. **카드 위계** → 결론 카드에만 강조 테두리와 빛을 쓰고, 나머지는 얇은 보더로 정리한다(같은 처리를 반복하지 않기).

## 적용 결과
위 13개 항목을 모두 적용했다. 스크린샷은 `docs/preview/`에 있다.
