## 1. 금·유가 전문가 리뷰

### 잘 된 점
- 점 예측 대신 확률 범위, 그리고 모든 모델의 과거 검증 결과를 공개합니다(금 시그널 IC ≈ 0 → "설명용", 범위 모델 80% 적중 78~82%).
- 룩어헤드 차단: 거시 지표 1일, EIA 재고 5일, CFTC 3일 발표 지연을 반영했고 단위 테스트로 확인합니다.
- 원유의 핵심 함정(롤오버, 2020-04-20 마이너스 가격, 환헤지 ETF, 레버리지 변동성 손실)을 숫자로 보여줍니다.
- 유가 지표 검증에서 직관과 반대인 결과(재고가 많을수록 이후 수익률이 높았음, IC +0.16)를 숨기지 않고 방향까지 표시합니다.

## 2. 디자인 · UX/UI 리뷰

### 비전문가 관점의 핵심 문제
메인 페이지의 정보는 충분했지만, **실제로 주문하기 직전에 필요한 다섯 가지**(지금 판단 · 얼마를 어떻게 · 어디서·비용 · 최악의 경우 · 언제 줄일지)가 다섯 개 섹션에 흩어져 있어 끝까지 스크롤해야 했습니다.

| # | 내용 | 조치 |
|---|---|---|
| U1 | 핵심 행동 정보가 흩어져 있음 | **[반영]** 히어로 바로 아래 "지금 거래한다면 · 꼭 볼 5가지" 카드(금·유가 공통 형식). 예산 입력과 연동되고, 각 칸을 누르면 근거 섹션으로 이동. 위험 신호는 주황색 |
| U2 | 모바일에서 한국어가 단어 중간에서 줄바꿈("수급 빡/빡") | **[반영]** 전역 `word-break: keep-all` |
| U3 | 모바일 상단 탭이 잘려 보이는데 가로 스크롤 가능하다는 단서가 없음 | **[반영]** 오른쪽 끝 페이드 처리 |
| U4 | 금/유가 전환 위치 | **[유지]** 모든 페이지 같은 위치의 `금 | 유가` 스위치, 메인↔메인·상세↔상세로 연결 |
| U5 | 유가 메인이 깁니다(데스크톱 약 7,500px). | **[유지]** 체크리스트로 첫 화면에서 결론을 얻고, 아래는 근거로 읽도록 구성. 상단 섹션 칩으로 바로 이동 가능 |

| U7 | 라이트 모드·모바일 가로 넘침 | 4개 페이지 모두 390px·1360px, 다크·라이트에서 가로 넘침 0 확인 |
